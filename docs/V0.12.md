# Питомо 0.12.0

## Фотографии товаров

Администратор выбирает до 5 JPEG/PNG/WebP по 5 МиБ. Форма показывает превью,
позволяет убрать файл и выбрать обложку. Создание с фото атомарно: ошибочное
изображение, повторный SKU или отказ хранилища не оставляют частичный товар.
Существующую галерею можно дополнить, удалить снимок и заменить обложку.

Сервер декодирует изображение, ограничивает 12 Мп, применяет ориентацию EXIF,
уменьшает до 2400 пикселей и сохраняет WebP без исходных метаданных. Прозрачность
PNG сохраняется. Имена — UUID; исходные имена файлов и пути не используются.
Файлы находятся в подкаталоге `products` существующего тома фото отзывов;
в резервное копирование этого тома включайте и подкаталог. Объектные URL превью
освобождаются после удаления из формы. Серверные удаления происходят после
коммита, новые файлы при откате убираются.

| API | Запрос | Ответ |
|---|---|---|
| POST `/api/v1/products/with-photos` | multipart `data`: JSON ProductCreate, повторяемые `files` | 201 ProductResponse |
| POST `/api/v1/products/{id}/photos` | multipart `file` | 201 ProductResponse |
| PATCH `/api/v1/products/{id}/photos/{photo_id}/cover` | без тела | 200 ProductResponse |
| DELETE `/api/v1/products/{id}/photos/{photo_id}` | без тела | 200 ProductResponse |

Изменения требуют администратора; браузерная сессия требует CSRF.
`image_url` остаётся обложкой, `images` содержит `{id,url}`. Старые демо-обложки
работают без загрузки. Nginx разрешает 32 МиБ только для создания с фото.
Галерея видна на странице товара, обложка — в каталоге.

## Согласия

Получите GET `/api/v1/privacy/config`; он возвращает текущую версию, документы,
признак черновика и доступность регистрации. Для регистрации добавьте в JSON:

```json
{"consent":{"version":"версия из privacy/config","subject_name":"Фамилия Имя Отчество при наличии","service":true,"analytics":false}}
```

GET `/api/v1/users/me/consents` возвращает текущий выбор своего аккаунта.
POST этого пути принимает такой же объект, как `consent` выше.
DELETE `/api/v1/users/me/consents/analytics` отзывает аналитику независимо от
версии. Missing/false/non-boolean обязательного согласия — 422, старая версия —
409, неполные документы в production — 503. Ретроспективного согласия старым
аккаунтам нет. [Содержание и ограничения](PRIVACY_KZ.md).

## Обновление

Миграция `0010_v012` добавляет `product_photos` и `consent_receipts`, сохраняя
старые данные и обложки. Сделайте проверенную резервную копию базы и тома фото,
затем пересоберите изображения и запустите `START.bat`. `.env` и
`.petshop-project-name` существующего проекта нужно сохранить. Пакет с исходниками
не содержит пользовательскую базу, загруженные фото, `.env` и API-ключи.
