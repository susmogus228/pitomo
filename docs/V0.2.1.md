# Petshop API v0.2.1 — patch release

## Что это за версия

**v0.2.1** — небольшое исправление поверх v0.2.0. Архитектура каталога, CRUD, Repository и Service слои не менялись.

Версия поднята с **0.2.0 до 0.2.1**, потому что это patch-изменение: исправлено поведение корневого URL без добавления нового крупного модуля или изменения архитектуры.

## Причина изменения

В v0.2.0 сервер запускался корректно, однако при открытии адреса:

```text
http://127.0.0.1:8000/
```

FastAPI возвращал:

```text
404 Not Found
```

Это происходило не из-за ошибки запуска. В приложении просто не был объявлен маршрут `GET /`.

Браузер также мог автоматически запросить `/favicon.ico` и получить `404`. Для backend API это нормальное поведение и не влияет на работу приложения.

## Что исправлено

В `app/main.py` добавлен корневой endpoint:

```http
GET /
```

Он возвращает краткую информацию о запущенном API:

```json
{
  "name": "Petshop API",
  "version": "0.2.1",
  "status": "running",
  "docs": "/docs",
  "health": "/health"
}
```

Теперь открытие `http://127.0.0.1:8000/` подтверждает, что приложение работает, и сразу показывает основные служебные ссылки.

## Что не изменилось

- каталог остаётся in-memory;
- 20 демонстрационных товаров сохраняются;
- CRUD товаров и вариантов не менялся;
- Repository и Service слои не менялись;
- публичные маршруты `/api/v1/...` совместимы с v0.2.0;
- PostgreSQL, авторизация, корзина и заказы по-прежнему не входят в текущую версию.

## Почему не v0.3

`v0.3` зарезервирована под следующий функциональный этап — **Users + Authentication**.

Добавление `GET /` не является новым крупным модулем. Поэтому по смыслу версионирования используется patch-номер:

```text
0.2.0 → 0.2.1
```

## Проверка

После запуска:

```powershell
.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

можно открыть:

```text
http://127.0.0.1:8000/
http://127.0.0.1:8000/health
http://127.0.0.1:8000/docs
http://127.0.0.1:8000/api/v1/products
```

## Запуск v0.2.1 с нуля

> Инструкция относится к отдельному архиву **v0.2.1**.

Требования: Python 3.12+. PostgreSQL/Docker не нужны.

```powershell
cd C:\Users\s.kirill\Desktop\petshop-api-v0.2.1
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn app.main:app --reload --no-use-colors
```

Проверка:

```text
Root     http://127.0.0.1:8000/
Swagger  http://127.0.0.1:8000/docs
Health   http://127.0.0.1:8000/health
```

## Обновление v0.2.0 → v0.2.1

Это patch-релиз без изменения хранилища и схемы данных.

1. Заменить код на v0.2.1.
2. Выполнить `pip install -r requirements.txt`.
3. Перезапустить Uvicorn.
4. Проверить `/`, `/health` и `/docs`.
