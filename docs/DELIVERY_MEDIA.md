# Изображения доставки Питомо

Пользователь выбрал первый макет доставки 13 октября 2026 года. Изображения
созданы встроенным `image_gen` по этому макету и сохранены в
`frontend/public/media/delivery-v013/`. Корпус, колёса, фон, облака и дым хранятся
отдельно. CSS анимирует эти изображения; текст и управление остаются обычным UI.

Для поломок используются отдельные спущенная шина и корпус с открытым капотом.
На последнем кот чинит двигатель снаружи. Дым хранит полупрозрачность, поднимается
и растворяется; системный режим уменьшенного движения отключает анимации.

Оригинальные PNG сохраняют пиксели результатов генерации. Сайт загружает
WebP-копии с прозрачностью и размерами для экранов; изображения колёс рассчитаны
на плотность более 2x. Восемь WebP-файлов вместе занимают около 350 КБ.
Арт-референс:
`verification/selected-delivery-v013.png`; исходный результат генерации
`exec-ec973cd9-8f4e-4be7-a325-c24eeb15aa18.png`.
