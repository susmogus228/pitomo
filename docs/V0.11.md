## Выгрузки для аналитики

Кнопки Excel и CSV доступны администратору в обзоре, заказах, товарах, истории
пополнений, пользователях, отзывах и скидках. На обзоре можно скачать все таблицы.
Состав полей и правила подсчёта описаны в [ADMIN_EXPORTS.md](ADMIN_EXPORTS.md).
Это таблицы для анализа. Для резервной копии PostgreSQL используйте
существующий [backup workflow](OPERATIONS.md).

## Редактор товаров

В разделе «Товары и остатки» нажмите «Добавить товар» или «Редактировать»
в строке таблицы. Укажите название, бренд, группу питомцев и товарный раздел.
Для корма обязателен состав, для аксессуара — материал. Новому товару нужен
хотя бы один вариант с уникальным SKU, ценой в тенге и начальным остатком.
Существующий товар сохраняет категорию, варианты можно добавлять и редактировать.

В форме показана базовая цена варианта. При действующей скидке её повторное
сохранение не применяет скидку ещё раз. Для существующих вариантов количество
пополняется через форму поступления с причиной и записью в журнале.
Загрузка фотографий и удаление товаров в редакторе этой версии не реализованы.
API ответа товара дополнен полями `composition` и `material`; прежнее
`description` сохранено. Изменение схемы базы не требуется.

## Адреса Казахстана

1. Зарегистрируйтесь в [Geoapify MyProjects](https://myprojects.geoapify.com/).
2. Создайте проект, откройте API Keys и скопируйте его ключ.
3. В локальную `.env` проекта добавьте `PETSHOP_GEOAPIFY_API_KEY=your_key`.
4. Повторно запустите `START.bat`, чтобы пересоздать API с новым окружением.

Никому не отправляйте `.env`. Ключ используется сервером; он не попадает в
JavaScript, ответы API, обычные логи и архив проекта. Не задавайте его через
`VITE_*`. Docker Compose передаёт его только серверным контейнерам.

В оформлении заказа введите город, улицу и дом. Подсказки появляются после трёх
символов и паузы 450 мс. Выбранный адрес устанавливает точку на карте.
Квартира, подъезд и этаж вводятся отдельно и не отправляются в Geoapify.
Изменение основного адреса сбрасывает прежние координаты. Клик по карте или
разрешённая пользователем геолокация запускают обратный поиск адреса.
Проверьте номер дома перед оформлением: данные карт могут быть неполными.

На странице ветклиник такой же поиск выбирает центр карты; сами клиники,
как прежде, загружаются из OpenStreetMap через Overpass. Подсказки ограничены
Казахстаном по параметру сервиса и коду страны в ответе. Вне страны обратный
поиск не подставляет адрес. Это поиск расположения, а не расчёт маршрута,
стоимости доставки или доступности курьера.

Без ключа, при ошибке сервиса или исчерпании лимита доступен ручной ввод адреса
и выбор точки на карте. Координаты не нужно печатать в форме. После ручного
выбора проверьте соответствие адреса и точки.

## Лимиты и данные

Geoapify получает только введённую строку основного адреса или координаты
для обратного поиска. Имя, телефон, квартира и комментарий заказа туда не передаются.
Результаты и поисковые строки находятся в памяти API до пяти минут, максимум
256 записей; в базу как история поисков они не записываются. В журнале HTTP
используется путь маршрута без строки поиска.

API ограничивает обращения к Geoapify до пяти в секунду. По умолчанию на процесс
разрешено 2800 обращений в сутки UTC; `PETSHOP_GEOAPIFY_DAILY_LIMIT` принимает
значения от 1 до 3000. Ошибки сервиса также учитываются. Повторный запрос из кэша
не расходует бюджет. Nginx дополнительно ограничивает обращения одного адреса.
Локальный счётчик сбрасывается при перезапуске API; при нескольких API-процессах
он не является общим. Общий расход ключа контролируется в кабинете Geoapify.
Текущий Compose запускает один API-процесс. Не используйте один ключ одновременно
в нескольких приложениях без контроля общего расхода.

На дату проверки бесплатный план предоставляет 3000 кредитов в день и до пяти
запросов в секунду; один запрос геокодирования стоит один кредит. Условия могут
измениться: [Geoapify pricing](https://www.geoapify.com/pricing/).
В интерфейсе рядом с подсказками сохранена ссылка на Geoapify, на карте —
атрибуция OpenStreetMap.

## API

- `GET /api/v1/geo/config`: `enabled`, `country_code=kz`; ключ не возвращается.
- `GET /api/v1/geo/address-search?q=Алматы%20Абая&lang=ru&limit=5`: массив `items`.
- `GET /api/v1/geo/reverse?lat=43.238&lon=76.945&lang=ru`: `item` или `null`.

Адрес содержит `label`, `lat`, `lon`, `country_code` и необязательные `city`,
`street`, `housenumber`, `postcode`. Языки — `ru` и `kk`. Неверные параметры:
422; лимит: 429; неподключённый или недоступный сервис: 503. Запросы к внешнему
сервису имеют таймаут, предел размера ответа и запрет перенаправления ключа.

Контракт сверён с официальными
[Autocomplete API](https://apidocs.geoapify.com/docs/geocoding/address-autocomplete/)
и [Reverse API](https://apidocs.geoapify.com/docs/geocoding/reverse-geocoding/).
Автотесты используют ответы сервиса, подставленные локально. Живая проверка
адресов Казахстана требует ключа пользователя и до его добавления не подтверждена.
