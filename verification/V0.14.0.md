# Проверка 0.14.0

Область: только N03, N04 и N07, включая согласованную гостевую корзину и решение
по жалобам администратором. Изменения описаны в [V0.14.0.md](../docs/V0.14.0.md).

- Бэкенд: 385 уникальных тестов прошли. Первоначальный полный запуск имел 383
  успешных проверки и одну регрессию числа SQL-запросов. После объединения
  обложки и галереи в один запрос исходная проверка и четыре связанные проверки
  прошли без ослабления лимита; одна из них новая. Это агрегат запусков, а не
  один полностью успешный полный прогон.
- PostgreSQL: 35 уникальных тестов прошли: 34 в общем запуске, одна позднее
  добавленная гонка повторного заказа отдельно. Проверены миграция с сохранением
  строк, metadata Alembic, идемпотентность и конкурентные ограничения. Для тестов
  создавались отдельные БД на validation-сервере; их затем удалили.
- Фронтенд: финальные 130 тестов, TypeScript и сборка прошли.
- Образ web собран из проверенного на Windows `dist` с тем же закреплённым
  nginx, entrypoint и конфигурацией. 112 файлов внутри образа сверены по SHA-256.
  Сборка TypeScript внутри WSL перестала продвигаться и была остановлена; её
  результат не считается успешной проверкой. Стандартный Dockerfile проекта
  сохранён. Подтверждение готового образа: `v014-web-image.json`.
- Браузер: 59 успешных утверждений в пяти сценариях, 390×844 и 1440×1000.
  Повторяющаяся проверка ошибок JavaScript относится к каждому сценарию отдельно.
  Ключи и полный список: `v014-summary.json`.
- Независимый Code Reviewer: pass. Обнаруженную гонку записи адреса после смены
  аккаунта исправили; reviewer повторно запустил соответствующий тест. Проверка
  дельты паузы объединения и единой SQL-выборки также прошла. Reviewer не выдавал
  чтение исходников за самостоятельное браузерное или PostgreSQL-тестирование.

Браузер проверил сетевой ответ, потерянный после записи, повтор без дублей,
частичные остатки, явный повтор объединения, отмену удаления, перенос в избранное,
адреса и оформление, изменение расчёта после 409, восстановление ключа повтора
после перезагрузки, выход без прежней частной корзины, фотографии/фильтры отзывов,
жалобы, скрытие/возврат и журнал, недоступность старого URL скрытой фотографии.

Записи магазина не использовались для тестов, меняющих данные. Снимки в `v014-ui`
показывают искусственные данные; синие квадраты — тестовые загруженные фотографии,
а некоторые заглушки вызваны намеренно недоступным URL. Внешние тайлы карты не
считаются гарантией работы провайдера в любой момент.

Обновление локальной установки и проверка туннеля записываются отдельно в
`v014-runtime.json` и `v014-public.json`. Резервные копии находятся в
`D:\Projects\pitomo\work\v014-purchases\private-backup`, за пределами ZIP.
Постоянное внешнее размещение и другие пункты гайда не подключались.
